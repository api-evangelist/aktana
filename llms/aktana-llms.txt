# Aktana (PharmaForceIQ)

> AI-driven commercial engagement platform for the pharmaceutical and life-sciences
> industry, operating as PharmaForceIQ since the January 2026 acquisition
> (aktana.com redirects in full to pharmaforceiq.com). The platform provides
> real-time "optichannel" orchestration coordinating digital and field marketing
> across channels to drive script lift and HCP (healthcare provider) adoption,
> with NPI-level dashboards tying engagement to outcomes.

## API surface

PharmaForceIQ publishes **no public API, no developer portal, no API reference and
no machine-readable contract**. This was verified, not assumed:

- No OpenAPI/Swagger at any probed path on pharmaforceiq.com, aktana.com, or
  app.pharmaforceiq.com.
- No GraphQL endpoint, no MCP server, no A2A agent card.
- Every /.well-known/ discovery path returns 404 on the marketing hosts.
- app.pharmaforceiq.com is a Laravel customer application that answers HTTP 200
  with `{"error":"Not Found","code":404}` for every unmatched path — its 200s are
  soft-404s, not documents.
- The customer help center at support.aktana.com is behind a Cloudflare bot
  challenge (HTTP 403).

Integration is delivered as a product and a professional-services engagement, not
as a self-serve developer program. The relevant surfaces are:

- [Aktana Omnichannel Data Interface](https://pharmaforceiq.com/aktana-omnichannel-data-interface/):
  a CRM-agnostic data schema layer, data integration framework with pre-built
  adapters, workflow connectivity, and an engagement template library. Integrates
  with Salesforce, Veeva, Adobe Experience Manager, OCE, Tealium and Lytics. No
  endpoint, schema or authentication documentation is published.
- [Aktana Omnichannel for Salesforce Marketing & Data Cloud](https://appexchange.salesforce.com/appxListingDetail?listingId=a0N3A00000FAMlzUAH):
  a Salesforce AppExchange managed package published by Aktana, Inc.
  Listed at $1,250 USD/Brand/month, annual contract, requiring Aktana Orchestrator
  and Tactic Genie subscriptions.
